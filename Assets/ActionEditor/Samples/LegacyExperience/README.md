# 功能体验样例

此样例扩展原有 Asset/Group/Track/Clip 模型，由 IMGUI 和原生 UI Toolkit 界面共用，不依赖 Combat，不修改原始资源或场景。

## 创建与打开

1. 等 Unity 自动编译完成，关闭并重开创建弹窗。
2. `NBC > Action Editor > Open Action Editor`（IMGUI）或 `Open Workbench`（原生 UI Toolkit）。
3. 点击欢迎页“新建资源”，类型选择“功能体验样例（预置轨道）”。
4. 建议文件名 `LegacyExperience`，选择 Assets 下的新路径并确认。创建后进入对应时间轴。

两个窗口共用一个当前文档、选择、Undo 和播放头，不是两个独立副本。保存使用当前唯一文档格式。保存会比较打开时的磁盘版本；文件被外部修改时拒绝覆盖并保留内存内容。切换脏文档时可以保存、取消或明确放弃；脚本重载使用 SessionState 恢复内存快照，但不等同于磁盘备份。

这不是空白模板：新建后预置 3 个组、7 条轨道、13 个片段/点事件，总长 6 秒。源码构造函数只在创建对象时提供初始内容，已有 JSON 的内容由反序列化恢复，不会在每次绘制时补回已删除片段。

## 建议体验顺序

| 内容 | 操作 |
|---|---|
| 区间与渐变 | 第一组第一轨，拖动片段、左右边缘伸缩，选中后在 Unity Inspector 修改 IN/OUT、长度及渐入渐出 |
| 交叉混合 | 第一组第二轨，有两段同类型重叠区间，观察交叉区与渐变控件 |
| 点事件 | 第一组第三轨，点事件无长度；右键空白新增“体验点事件” |
| 内循环 | 第二组第一轨，右键循环片段查看匹配长度/循环相关菜单，修改周期、倍速和偏移 |
| 常用属性 | 第二组第二轨，Inspector 中修改文字、数值、bool、枚举、颜色、向量、曲线；切换显示模式体验条件字段和可选音频资源路径 |
| 列表 | 属性片段的“参数列表”折叠项，可新增/删除并修改键值 |
| 分组/轨道 | 折叠第一、二组，展开第三组；右键轨道头体验锁定/解锁、激活/停用及添加轨道 |
| 时间与视图 | 标尺定位、播放/暂停、逐步定位、普通滚轮缩放、中键平移、底部可见时间范围、吸附与秒/帧设置 |
| 状态预览 | 顶部“样例状态预览”，观察色块、当前区间、循环相位和播放头之前的标记 |

预览只计算和绘制窗口内状态；资源路径字段只用于选取/存储路径，不会播放音频或创建对象。无需 Animator、角色、音频或特效素材。

## 当前能力与限制

- 保存、复制/剪切/粘贴、轨道副本、重命名、Undo/Redo 已接入共用 JSON 会话。新建/另存仅允许新路径，不覆盖其他文档。
- UI Toolkit 按原版还原顶部 40px 播放区、文档选择/类型 Header/最后保存时间/图标按钮、第二行标尺、轨道头图标与菜单、28px 行距、16px 底部范围、居中欢迎页和独立 Unity Inspector。选中片段使用白框，类型名称居中，Inspector 保留横排 IN/长度/OUT、范围滑块和 Blend In/Out；设置由磁吸右侧齿轮打开。截图覆盖停止、暂停选中、循环、滚动、欢迎页和属性面板，最终外观仍需用户体验验收。
- 移除了之前自行添加的顶部文字保存/属性/常驻预览和循环数字字段。样例预览只由此资源类型 Header 提供；其他类型不会多出样例入口。轨道头可拖动重排，片段可拖动及拉伸，Esc/失去捕获取消；Shift 可暂时跳过邻居磁吸。
- 拖动单个或多个事件时，按原版在选中整体的最早起点/最晚终点显示纵向辅助轴和两位小数时间标签：普通位置为灰色虚线，与吸附参考时刻重合时为白色实线。拉伸仅显示对应一侧，松开或取消后隐藏；辅助轴覆盖标尺到时间轴底部，不拦截鼠标。
- `HeaderBase.CreateGUI()` 可提供原生自定义 Header，当前样例已实现。既有 `OnGUI()` Header/Inspector 不会自动嵌入原生界面，未声明任意业务扩展已经转换。Unity 内建 Toolkit/IMGUI 控件的字体、滑块皮肤和抗锯齿仍有细微差别。
- 资源路径字段采用原有字符串格式。任意 UnityEngine.Object 字段的跨重启持久引用没有本轮验收保证，不将路径样例当作 GUID 引用方案。
- 不包含真实动画、音效、特效或 Combat 预览。状态窗口是直接按播放头求值，不冒充旧播放回调的可靠性验证。
