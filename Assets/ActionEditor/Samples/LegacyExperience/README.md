# 功能体验样例：从新建到独立导出

这是本工程唯一的入门操作正文。先在独立样例中练习，不打开或覆盖正式资源。中文按钮后标注必要的英文名称；菜单路径不随语言切换。

## 准备

等 Unity 编译完成。在 Project 窗口中创建专用文件夹，例如 `Assets/ActionEditorPractice`，只存放本次练习的新文件。以下路径必须不存在，不要使用已有用户资源。当前只有一个共用文档、选择、Undo 历史和播放头；同时打开两个界面也不是两个副本。若当前有未保存内容，请先保存，或在切换提示中选择“取消”返回，不能为了练习随意放弃正式修改。

## 最短操作链

| 步骤 | 真实入口与初态 | 可观察的结果 |
|---|---|---|
| 1. 打开任一界面 | Unity 菜单 `NBC > Action Editor > Open Action Editor` 为 IMGUI，`NBC > Action Editor > Open Workbench` 为原生 UI Toolkit。无资源时显示欢迎页。 | 欢迎页有“新建资源 / New resource”和“打开资源 / Open resource”。已经打开资源时，用文档栏新建图标，或返回欢迎页后新建。 |
| 2. 新建预置样例 | 点击“新建资源”；资源类型选“功能体验样例（预置轨道） / Feature sample (preset tracks)”，资源名称填 `Practice`。点击“创建并打开 / Create and open”，在保存框选择 `Assets/ActionEditorPractice/Practice.json`，核对确认框后再创建。 | 仍在发起界面编辑。不是空模板：3 个分组、7 条轨道、13 个区间/点事件，总长 6 秒，可见范围 0–7 秒。第三组初始折叠，其中有锁定和未激活轨道。 |
| 3. 查看并修改属性 | 单击第一组“区间与渐入渐出”轨道的“准备”片段。在 Unity Inspector 中查看 IN、长度、OUT 和业务字段。将“标题”改为 `Tutorial`，按 Enter 或移开焦点提交。 | 初始 IN 为 0.25 秒，长度 1.5 秒；片段信息与 Inspector 同步。修改标题不改变时间。不要混淆片段名称与业务“标题”字段。 |
| 4. 移动和拉伸 | 在片段中部按左键向右拖动，松开；再拖动右边缘缩短（避免碰到下一片段）。数值练习可在 Inspector 把 IN 调为 0.5 秒、长度调为 1.25 秒。 | 中部拖动改变位置，右边缘改变长度；不能拖动锁定片段。磁吸和时间步长可能影响落点，检查最终 IN/长度，不凭鼠标像素猜值。Shift 临时绕过邻居磁吸，但不取消时间步长。Esc 取消当前拖动。 |
| 5. Undo / Redo | 保持时间轴或 Inspector 焦点，Unity `Edit > Undo`，再 `Edit > Redo`（也可用平台标准撤销/重做快捷键）。文本输入中快捷键可能先作用于文字。 | 最近一次完整修改撤销，再重做恢复，不产生半次拖动；撤销后对象可能已重建，重新选择片段查看。 |
| 6. 播放与状态预览 | 顶部资源自定义按钮“样例状态预览 / Sample state preview”打开状态窗口。点击播放三角形，观察播放头；暂停后拖动标尺定位到约 0.75 秒，最后点击停止。 | 状态窗口显示色块、当前区间、循环相位和播放头之前的标记；停止后播放头归零。标记是当前时刻求得的状态，不是事件触发日志。无需进入 Unity PlayMode。 |
| 7. 保存 | 点击文档栏保存图标（悬停提示“保存 / Save”），或在时间轴焦点下 Ctrl+S。 | 内容保存到当前 `Practice.json`，未保存标记消失，最后保存时间更新。若文件被外部修改，拒绝覆盖并保留内存内容；不要反复保存试图绕过保护。 |
| 8. 关闭并重开 | 保存后关闭编辑窗口；从步骤 1 的同一菜单重开。若仍有当前资源也可用文档选择图标重新选取；欢迎页点“打开资源”。选择刚才的 `Practice.json`。 | 标题字段和调整后的时间保留，不重新补回构造器预置内容。两界面共用当前资源，所以关闭一个界面不等于清空文档；关闭窗口会停止共享播放。 |
| 9. 独立导出 | 右键文档栏保存图标，选“导出 / Export”；“文件格式 / File format”当前只有真实实现的 `JSON (.json)`。点击“导出”，选择不存在的 `Assets/ActionEditorPractice/Practice-Export.json`。 | 新文件是当前内容的独立副本。当前来源仍为 `Practice.json`，导出不清除未保存修改、不重置 Undo/选择/播放状态，也不覆盖源文件或已有文件。取消文件框不会写文件。 |

## 保存、另存为、导出的区别

- **保存**更新当前来源；无来源时请求新路径。采用完整快照、读回校验和可靠字节提交，失败不把未提交内容标成已保存。
- **另存为 / Save as…**在保存图标右键菜单中选择。只接受新路径，成功后当前来源改为新文件，之后“保存”写入新来源。
- **导出**只生成独立副本，包含尚未保存但已提交的编辑；不改变当前来源或保存基线。活动拖动/未结束编辑必须先完成或取消。
- 切换脏文档提示“保存 / 取消 / 放弃”。取消保留当前内容与来源；放弃明确舍弃未保存内容。不要把取消当成放弃，也不要把导出当成保存。
- 齿轮“偏好设置”中的自动保存间隔按秒计，0 表示关闭；已有来源的脏文档在间隔到达且无活动编辑时尝试保存，无来源不弹出后台保存框。自动保存成功会更新保存基线，不保留无限历史。练习 Undo 时先查看间隔，设置会写个人偏好，自动化重放不修改它。
- 脚本重载通过 SessionState 恢复快照和来源/基线，但不是磁盘备份。当前采用唯一 `actioneditor.json` v1 格式，旧裸根格式不提供兼容读取或自动迁移；不要拿正式旧文件试覆盖。

## 继续体验哪些内容

- 第一组第二轨：两个同类片段的交叉混合与渐变。第三轨：零长度点事件，右键空白新增“体验点事件”。
- 第二组第一轨：内循环周期、倍速、偏移和匹配长度菜单。第二轨“属性练习”：文字、数值、bool、枚举、颜色、向量、曲线、条件字段和参数列表。
- 第三组：展开后体验锁定/解锁及激活/停用。滚轮缩放、中键平移、底部范围和秒/帧设置都不等同于修改片段内容。

## 最小业务接入与边界

Runtime 业务 `Asset` 管根字段及分组，`Group` 组织轨道，`Track` 限制可挂载片段，`Clip` 保存时间和业务参数。沿样例使用 `Name`、`MenuName`、`Attachable` 等 Attribute，完整类型/字段身份用于持久化，不要为改显示名称改命名空间或字段键。Editor 扩展负责业务属性视图、Header 和预览；原生 Header 用 `HeaderBase.CreateGUI()`，IMGUI Header 用 `OnGUI()`，不能假定所有自定义界面自动转换。参考源码位于 `Runtime/Samples/LegacyExperience` 和 `Editor/Samples/LegacyExperiencePreview.cs`，类型名中的 Legacy 是已有身份，不是产品版本。

样例状态窗口只按播放头求值绘制，不生成场景对象、不播放动画/音频/特效、不执行 Combat 或真实游戏逻辑。资源路径字段只是字符串，不是音频播放能力。受控 Unity Object 引用支持当前工程持久主/子资产的 GUID/localFileId；临时/场景/无有效身份引用不能保存，路径字符串不能冒充持久引用。

两种绘制控件的字体、滑块皮肤和抗锯齿可能不同。实际工程验证与尚待人工体验的范围只记在[唯一任务清单](../../../../.codex/tasks/action-editor-refactor.md)。教程重放不代替用户完成 H01–H09。
