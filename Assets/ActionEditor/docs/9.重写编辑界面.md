# 业务界面扩展

扩展声明位于[ViewExtensionContracts](../Editor/Extensions/ViewExtensionContracts.cs)，真实双原生实现见[FeatureSampleComposition](../Editor/Composition/FeatureSampleComposition.cs)。业务数据程序集不依赖这些Editor类型。

| 界面 | 工具栏 | 属性 |
|---|---|---|
| IMGUI | `CustomHeader`绑定`HeaderBase.OnGUI(EditorExtensionContext)` | `CustomInspectors`绑定`InspectorsBase`或具体领域Inspector |
| UI Toolkit | `ToolkitHeader`绑定`ToolkitHeaderView.CreateGUI(EditorExtensionContext)` | `ToolkitProperties`绑定`ToolkitPropertyExtension.Populate` |

绑定使用明确目标类型；是否适用于子类由声明显式指定，冲突会报告双方类型。两种界面分别实现原生绘制/控件，不用IMGUIContainer替代Toolkit扩展。

扩展读取所属窗口注入的`EditorExtensionContext`，属性写入经所属`PropertyPresenter`执行，不查找全局窗口、不直接写文档、不持有另一套作者会话。逐窗绑定负责订阅与释放，预览资源必须有明确所有者。完整边界见[产品合同](../../../Docs/ActionEditor-Contracts.md)。
