# 业务字段

文档、组、轨道和片段共享字段描述与属性编辑用例。实际声明见[FeatureSampleDocument](../Runtime/Samples/FeatureSample/FeatureSampleDocument.cs)中的区间、点事件及循环片段；当前字段元数据实现为[PropertyDescription](../Runtime/Metadata/PropertyDescription.cs)。

- `MenuName`指定字段标签，`HideInInspector`隐藏字段但不取消持久化。
- `OptionParam`关联整数常量目录，`OptionSort`控制选项顺序，`OptionRelateParam`按其他字段值控制可见性。隐藏值仍保存。
- Unity的`Range`声明数值控件范围。显示精度不改变持久化float原始位。
- `SelectObjectPath`让字符串字段通过资源选择控件取得项目路径。字符串路径不等同于持久Unity对象引用；后者按GUID/localFileId保存。
- 原生字段控件覆盖数值、布尔、字符串、枚举、颜色、向量、矩形、边界、曲线和Unity对象；数组/List及嵌套对象通过字段路径编辑。控件支持不等于任意.NET类型都可序列化，受控存储类型见[产品合同](../../../Docs/ActionEditor-Contracts.md)。

延迟输入在确认后提交，Esc取消草稿；选择、Undo或文档变化会使旧字段路径失效。同类型多选按整批校验、隔离复制、单事务提交，不能部分写入锁定对象或失效路径。null与空集合分别保留。
