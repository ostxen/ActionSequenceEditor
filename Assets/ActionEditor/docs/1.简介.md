# ActionEditor

ActionEditor用于编辑可扩展的行为时间轴。IMGUI与UI Toolkit是两个原生界面，共享文档、选择、剪贴板、播放头与Undo，每个窗口独立保留视域和输入捕获。

文档由有序根项、组、轨道和片段组成，根组与独立轨道可以交错排列。业务类型声明数据和能力，编辑用例统一校验，Presenter组织显示状态，视图只绘制和上报意图。文件采用严格的`actioneditor.json` version 2。

从[功能体验样例](../Samples/FeatureSample/README.md)开始操作；精确数据和扩展边界见[产品合同](../../../Docs/ActionEditor-Contracts.md)。
