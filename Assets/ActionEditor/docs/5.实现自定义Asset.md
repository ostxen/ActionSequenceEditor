# 自定义文档

业务文档继承`NBC.ActionEditor.Domain.ActionDocument`，使用`[Serializable]`和`[Name]`声明。抽象基类不出现在创建列表中。当前完整实现见[FeatureSampleDocument](../Runtime/Samples/FeatureSample/FeatureSampleDocument.cs)，入门操作只维护在[功能体验样例](../Samples/FeatureSample/README.md)。

`RootItems`只保存Group或Track，保持任意交错顺序。组包含轨道，轨道包含片段，不允许嵌套组。构造器可以预置内容，但反序列化必须完整采用输入集合，不能追加预置项。

公共实例字段及`[SerializeField]`字段参与持久化，属性、静态字段和`[NonSerialized]`字段不参与。业务类型应位于Runtime程序集；Editor-only、测试与验证类型不进入生产类型目录。类型身份精确包含命名空间和程序集，字段必须完整，具体约束见[产品合同](../../../Docs/ActionEditor-Contracts.md)。
