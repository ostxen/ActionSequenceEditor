# 自定义片段

片段继承`ActionSequenceEditor.Domain.TimelineClip`，点事件使用`PointClip`，支持交叉混合的区间使用`CrossBlendClip`。使用`[Serializable]`、`Name`、`Category`、`Attachable`等声明类型与允许轨道；实际代码见[功能样例片段](../Runtime/Samples/FeatureSample/FeatureSampleSequence.cs)。

- 区间通过`Length`表达时长，交互编辑最短0.01秒；点事件有效时长固定为零，不能拉伸。
- `BlendIn`/`BlendOut`表达渐入渐出，交叉混合值由邻接关系计算，不替代作者参数。
- `ISubClipContainable`提供源周期、速度和偏移，匹配长度使用同一领域能力。
- `IsValid`表达业务参数是否可用，`Info`提供显示说明；无效参数可以在属性面板定位，不通过保存偷偷修复。

预览执行器与作者对象分离，资源由预览会话创建、采样和释放。不要让绘制方法直接修改作者模型或拥有运行时资源。时间、引用和存储边界见[产品合同](../../../Docs/ActionEditor-Contracts.md)，操作只维护在[功能体验样例](../Samples/FeatureSample/README.md)。
