# 自定义轨道

轨道继承`ActionSequenceEditor.Domain.TimelineTrack`。使用`[Serializable]`声明可持久化类型，`Name`、`Description`、`ShowIcon`和`Color`描述菜单及显示。具体声明见[功能样例轨道](../Runtime/Samples/FeatureSample/FeatureSampleSequence.cs)。

`Attachable`限定允许的父类型，`Unique`限定同一容器中的唯一性。未指定父类型的轨道可以进入允许的根或组；指定父类型后，创建、菜单和移动必须满足同一规则。组与根轨混排不改变轨道只能属于一个容器的约束。

激活与锁定状态由领域模型表达，继承锁定会阻止编辑。视图不自行决定挂载或唯一性，提交时由共享用例重验。精确规则见[产品合同](../../../Docs/ActionEditor-Contracts.md)。
