# 时间轴输入

时间轴获得焦点且未编辑文本时，两个界面使用相同的编辑快捷键：

| 输入 | 动作 |
|---|---|
| Ctrl/Cmd+C、X、V、D | 复制、剪切、粘贴、重复选择 |
| Ctrl/Cmd+S | 保存当前共享文档 |
| Ctrl/Cmd+Z、Shift+Z | 撤销、重做 |
| Delete | 删除选择 |
| Esc | 取消本窗口拥有的手势 |

播放、暂停、停止与逐帧定位使用顶部控件。鼠标滚轮以指针时间为锚点缩放，中键拖动平移；标题区滚轮用于纵向滚动。操作流程见[功能体验样例](../Samples/FeatureSample/README.md)。
